# Blessed Bob bootstrap

This directory contains the Bob executable used to build and verify Orbiter
v0.1.

- Source: https://github.com/MicroRJ/bob
- Bob commit: `ca2e98390116f2a928d0c2903fd5bad0b7cf33b5`
- ELF commit: `09bf9e165c133d861dbac60dfb389ac109d8d830`
- Platform commit: `ffdbfcae0cf277b76ab97d173dfabf37be57c739`
- SHA-256: `E37324D2A0580A22CDAA433C36E052F6720500A7DDA2437D05E9B6CE5894A858`

The executable is included so a fresh Orbiter checkout can build without a
separate Bob checkout. Its MIT license is included alongside it.
